# PWA Icons Note

For production deployment, replace these placeholder files with actual PNG icons.

## Required Icon Sizes
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Design Recommendation
Create icons with the Nova branding:
- Gradient background (blue #3b82f6 to purple #8b5cf6)
- White "N" or sparkle ✨ symbol
- Rounded corners for modern look

## Tools to Generate Icons
- Use online PWA icon generators like:
  - https://www.pwabuilder.com/imageGenerator
  - https://realfavicongenerator.net/
- Or use design tools like Figma, Sketch, or Photoshop

For development/testing, the app will work without icons but will show broken image placeholders.
